# Smart Academic Notice Analyzer and Deadline Tracker

A mobile application that analyzes academic notices, extracts important information such as deadlines, categories, and priorities, and generates reminders for students.

## Features

- OCR-based notice extraction
- PDF notice processing
- Deadline detection
- Automatic reminder generation
- Notice categorization
- Priority detection
- Notice summarization

## Technologies Used

- Python
- OCR (Tesseract)
- NLP
- Flask (planned)
- React Native / Frontend (planned)
